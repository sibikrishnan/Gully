# MVP In-Scope Features

**Purpose:** Core features that MUST be built for Phase 1 MVP.

---

## ✅ Feature 1: User Authentication
- Email/password signup
- Login with JWT
- Profile creation

## ✅ Feature 2: User Profiles
- Name, avatar, bio
- Sports preferences (pingpong, paddle, pickleball,cricket,football)
- Skill level selection

## ✅ Feature 3: Team Creation & Management
- Create team
- Invite members via email
- Accept/decline invitations
- Manage roster (add/remove)

## ✅ Feature 4: Challenge System
- Send challenge (user-to-user or team-to-team)
- Accept/decline challenge
- Propose match date/time/location

## ✅ Feature 5: Match Scheduling
- Schedule confirmed match
- Basic match details (date, time, location, sport)
- Match status tracking

## ✅ Feature 6: Result Submission
- Submit match results
- Simple verification (both teams confirm)
- Win/loss/draw recording

## ✅ Feature 7: Basic Stats & Leaderboard
- Win/loss record
- Match history
- Simple leaderboard (by sport)

---

**Total Features:** 7 core features for MVP validation
