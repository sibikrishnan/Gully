### 🔒 TRACKER UPDATE PROTOCOL (NON-NEGOTIABLE)

**CRITICAL: All task work MUST update tracker files. No exceptions.**

**When to Update:**
1. **Task Start** → Update `status/current.json` with `"status": "in_progress"`
2. **Task Complete** → Update both:
   - `status/current.json` → `"status": "completed"`
   - `history/active.json` → Append task completion entry
3. **Bug Found** → Create `bugs/BUG-{ID}.json`
4. **Phase Complete** → Update `status/phases/P{N}.json`

**Update Sequence (ALWAYS follow):**
```bash
# 1. Start task
jq '.currentTask.status = "in_progress"' status/current.json > tmp && mv tmp status/current.json

# 2. Complete task
jq '.currentTask.status = "completed"' status/current.json > tmp && mv tmp status/current.json
jq '.tasks += [{ TASK_ENTRY }]' history/active.json > tmp && mv tmp history/active.json

# 3. Update phase progress
jq '.currentPhase.progress.tasksComplete += 1' status/current.json > tmp && mv tmp status/current.json
```

**Required Fields in history/active.json:**
- `id`, `phaseId`, `title`, `status`, `completionDate`
- `execution` (tokens, duration, approach, subtasks)
- `tests` (total, passing, coverage, distribution)
- `learnings`, `filesCreated`, `filesModified`

**Validation:**
- NEVER skip tracker updates
- ALWAYS use absolute paths: `/Users/sibikrishnan/Documents/Gully/tools/tracker/data/`
- VERIFY file writes succeeded with `cat` after update

## 🚨 FILE DISCIPLINE (HOOK-ENFORCED)

**CRITICAL: Every file in .claude/ loads at EVERY session startup**

**Token Budget Awareness:**
- 1,000 line file = ~3k tokens
- Loaded at EVERY session = 3k × N sessions
- 10 sessions = 30k wasted tokens
- **Target: .claude/ = 5k tokens total**

**BEFORE Write/Edit:** Check path & line limits (`.claude/FILE_BUDGETS.json`)

- **NEVER create files in .claude/ without checking if it belongs in docs/**
