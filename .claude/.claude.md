## 🏗️ Architecture (Non-Negotiable)

**MODULAR MONOLITH** (NOT Microservices)
- Service-oriented structure, single Node.js process
- Clear boundaries, runs as monolith
- Easy container migration later (post-funding)

**Stack:**
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL + Redis (Docker, local only)
- Auth: Passport.js + JWT (self-hosted)
- Frontend: Next.js (Week 3+)

**Service Boundaries:**
- User Service: `/api/auth/*`, `/api/users/*`
- Team Service: `/api/teams/*`
- Match Service: `/api/challenges/*`, `/api/matches/*`
- Stats Service: `/api/stats/*`

For details: `/gullycontext arch`

## 🔧 Git Workflow (AUTO-COMMIT MODE)

**User delegated git to Claude - Commit automatically, don't ask**

**Auto-Commit Triggers:**
1. Todo items marked complete
2. Logical units finished (feature done, tests pass)
3. Files created/modified in related batch
4. Bug fixes completed

**Auto-Commit Process:**
1. Run `git status && git diff`
2. Stage files (exclude secrets)
3. Create commit (conventional commits + context metadata)
4. Commit + push immediately
5. Brief confirmation: "✅ Committed: [message]"

**Only Ask When:**
- Pushing to main/master
- Force push required
- Secrets detected in staged files

**Commit Format:**
```
<type>: <description>

**Context Loaded:** [sections used]
**Metadata:** [Task: X.Y] [Module: service] [Status: status]

🤖 Generated with [Claude Code](https://claude.com/claude-code)
Co-Authored-By: Claude <noreply@anthropic.com>
```
