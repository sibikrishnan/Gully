# Gully - Development Roadmap

## Phase 1: Foundation (Months 1-3)

### Month 1: Setup & Core Auth
**Week 1-2:**
- Project setup (repos, CI/CD, environments)
- Database schema design
- API structure/boilerplate
- Mobile app scaffold

**Week 3-4:**
- User authentication (signup/login)
- Profile creation/editing
- Sports selection
- Basic UI/UX implementation

**Deliverables:**
- Users can register and create profiles
- Tech stack validated
- Development environment ready

---

### Month 2: Teams & Challenges
**Week 1-2:**
- Team creation/management
- Team invitations
- Team roster display

**Week 3-4:**
- Challenge creation flow
- Challenge acceptance/decline
- Challenge browsing/search
- Notification system basics

**Deliverables:**
- Users can form teams
- Teams can challenge each other
- Basic notification system live

---

### Month 3: Matches & MVP
**Week 1-2:**
- Match scheduling
- Result submission
- Result verification flow
- Match history

**Week 3-4:**
- Basic stats tracking
- User/team win-loss records
- Bug fixes
- MVP testing & deployment

**Deliverables:**
- End-to-end match flow complete
- MVP launched to alpha testers
- Initial feedback collected

---
