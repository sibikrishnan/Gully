## Instructions to Human

### Session Startup Checklist
1. **Start Docker services** (if not already running):
   ```bash
   cd backend && docker compose up -d
   ```

2. **Run /verify command** (manual step - Claude cannot automate this):
   - Type `/verify` in Claude Code
   - Claude will run checks and report status
   - This gives you a quick health check without wasting tokens

3. **Check context** with `/status`:
   - Shows current week, last task completed, next task
   - Quick 3-5 sentence summary
   - No need to explain full project history

4. **Continue work** with `/continue`:
   - Auto-loads next task from TASK_HISTORY.md
   - Shows what will be done
   - Asks for confirmation before starting

### After Each Task Completion
- Verify TASK_HISTORY.md was updated by Claude
- Check that commit message follows the template
- Optionally run `/verify` again to confirm everything still works
