# Future Scope

## External LLM Review System

### Concept
Integrate an external coding assistant or system design expert LLM model (e.g., Gemini) to review plan results generated by Claude during the planning phase.

### Implementation Approach
- Slash command: `/gullygeminireview [custom instructions]`
- Default behavior: Send plan result summary + current context for expert review
- Custom instructions allow specialized reviews (security, architecture, scalability, etc.)

### Benefits
- Cross-model validation of architectural decisions
- Different perspectives on implementation approaches
- Catch design flaws early in planning phase
- Specialized domain expertise (security, performance, scalability)

### Use Cases
- Review system design decisions before implementation
- Validate security architecture
- Performance and scalability assessment
- API design review
- Database schema validation

### Technical Requirements
- MCP server setup for external LLM integration
- Context packaging (plan result + relevant files)
- Response formatting and integration
- Review history tracking

### Priority
Low - Focus on core feature implementation first. Revisit when system design complexity increases.
