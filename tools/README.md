# Tools

This directory contains development tools and utilities for the Gully project.

## Structure

- **tracker/** - Project management and task tracking system
  - Centralized storage for task definitions (`data/tasks/`)
  - Project status tracking (`PROJECT_STATUS.json`)
  - Task execution history (`TASK_HISTORY.json`)
  - Bug tracking (`BUG_TRACKER.json`)
  - Dashboard UI for visualization
  - PM agent integration point

## Usage

Refer to individual tool directories for specific usage instructions.

See `tracker/README.md` for detailed tracker documentation.
